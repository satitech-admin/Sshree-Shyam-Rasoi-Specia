# Sshree Shyam Rasoi Special

Cinematic, mobile-first restaurant website concept for **Sshree Shyam Rasoi Special**, Rau, Indore.

## Highlights
- Pure vegetarian / North Indian positioning
- Cinematic responsive hero and food gallery
- Menu highlights and WhatsApp ordering
- Google Maps embed and local SEO schema
- Zomato / Maps / Call touchpoints
- GitHub Pages deployment workflow

Built by Sati Technologies.
